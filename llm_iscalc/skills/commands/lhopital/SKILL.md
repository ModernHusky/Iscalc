# lhopital
> 洛必达法则求不定式极限。

## 指令

### 语法格式

```
l'Hopital's rule
```

### 参数说明

无参数。该命令自动对分子分母同时求导。

## 使用时机

当极限是不定型时：
- **0/0 型**：分子分母极限都趋于0
- **∞/∞ 型**：分子分母极限都趋于无穷

## 适用目标类型

| 目标类型 | 适用性 |
|---------|--------|
| `LIM {x -> a}. f(x)/g(x)`（0/0型）| ✅ |
| `LIM {x -> a}. f(x)/g(x)`（∞/∞型）| ✅ |
| `LIM {x -> oo}. f(x)/g(x)` | ✅ |
| 非分数形式的极限 | ❌ |
| 确定型极限 | ❌ |

## 工作流程

1. **识别分数结构**：确认极限表达式是分数形式 `f(x)/g(x)`
2. **检查不定型**：验证直接代入得到 0/0 或 ∞/∞
3. **求导操作**：对分子 `f(x)` 和分母 `g(x)` 分别求导
4. **生成新极限**：`LIM {x -> a}. f(x)/g(x)` → `LIM {x -> a}. f'(x)/g'(x)`
5. **继续求值**：可能需要多次应用或使用 `simplify`

**数学原理**：
洛必达法则：若 `lim f(x) = lim g(x) = 0`（或 ∞），则
`lim f(x)/g(x) = lim f'(x)/g'(x)`（若右边极限存在）

## 注意事项

- **必须是分数形式**：极限表达式必须能写成 `f(x)/g(x)` 的形式。
- **确认不定型**：直接代入如果不是 0/0 或 ∞/∞，则不应使用此规则。
- **多次应用**：如果求导后仍是不定型，可以再次应用洛必达法则。
- **替代方法**：某些情况下使用 `rewrite` 变形后再 `simplify` 更简单。

> 💡 **替代方案**: 当洛必达法则不适用时，考虑加载 `<|load_skill|>rewrite<|end_load_skill|>` 进行代数变换。

## 示例

### 示例1: 0/0 型

表达式: `LIM {x -> 0}. sin(x)/x`

```
l'Hopital's rule
```

变换为: `LIM {x -> 0}. cos(x)/1`

```
simplify
```

结果: `1`

### 示例2: ∞/∞ 型

表达式: `LIM {x -> oo}. log(x)/x`

```
l'Hopital's rule
```

变换为: `LIM {x -> oo}. (1/x)/1`

```
simplify
```

结果: `0`

### 示例3: 多次应用 (来自 theories/)

```
calculate LIM {x -> 0}. (exp(x) - 1 - x) / x^2
    l'Hopital's rule
    # 结果：LIM {x -> 0}. (exp(x) - 1) / (2*x)  仍是 0/0 型
    l'Hopital's rule
    # 结果：LIM {x -> 0}. exp(x) / 2
    simplify
    # 结果：1/2
done
```
